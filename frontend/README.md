# SkillSwap

A creator gig marketplace where young creators can showcase their skills and clients can discover and book them.

## Hackathon Details

- Hackathon: Azisly.ai Hackathon
- Track: Track 2 — Create Economy
- Hackathon ID: AZIS-MWAMW2
- Team: Shaikthabasum2006's Team

## Features

### 1. Post a Gig
Creators can list a service with:
- Title
- Category
- Rate
- Description

### 2. Browse & Search
Users can browse available gigs and search/filter them by category.

### 3. Book a Gig
Clients can select a gig, submit a booking request, and receive confirmation.

### 4. Creator Dashboard
Creators can view incoming booking requests and accept or decline them.

### 5. My Bookings
Clients can view their bookings and see their current status:
- Pending
- Accepted
- Declined

## Decision Points
